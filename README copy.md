# VietnameseInput Binaries

This repository is used to host release artifacts and dSYMs for the [VietnameseInput SDK][Repository]. Each release tag in this repository matches an SDK version in the [main repository][Repository].


## Website

The [VietnameseInput website][Website] has information about the SDK, a blog with the latest news, pricing info, etc.


## Repository

The [VietnameseInput repository][Repository] contains the SDK, as well as a demo app that shows how to use it.


## Documentation

The [VietnameseInput documentation][Documentation] has a getting-started guide, articles, code samples, etc.


## Binaries

The [VietnameseInput binaries][Binaries] contains the SDK and its releases.
